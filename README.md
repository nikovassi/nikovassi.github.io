# Nikolay Vasilev — личен блог

Личният сайт/блог на Николай Василев.

🔗 Сайтът е достъпен на: https://nikovassi.github.io/

## Как да добавяш съдържание (без да пипаш код)

Сайтът е направен така, че новите статии да се появяват автоматично, само като качиш `.md` файл в правилната папка тук, в GitHub. Не е нужно да редактираш `index.html`, `styles.css` или `script.js`.

### 📝 Да добавиш нова статия

1. Отвори папката [`posts`](posts) в това repository.
2. Натисни **Add file → Create new file** (или провлачи готов `.md` файл през **Add file → Upload files**).
3. Ако създаваш файл направо в GitHub, кръсти го с кратко латинско име, например `moqta-nova-statia.md` — това име определя адреса на статията.
4. В началото на файла пиши кратък "frontmatter" блок по този образец:

   ```
   ---
   title: Заглавието на статията
   date: 2026-10-01
   excerpt: Едно-две изречения, които се показват в листинга на блога.
   cover: images/post-cover-1.svg
   ---
   ```

5. Под него пишеш статията с обикновен Markdown:
   - `## Подзаглавие` за секции
   - `**удебелен текст**` и `*курсив*`
   - `- елемент` за списъци, `1. елемент` за номерирани списъци
   - `[текст](адрес)` за линкове, `![описание](адрес-на-снимка)` за снимки
   - `> цитат` за цитат
   - `` `код` `` за инлайн код, и тройни обратни кавички (```` ``` ````) за блок код
6. Натисни **Commit changes**.

Статията се появява автоматично в блога до няколко секунди — подредена по дата, най-новите най-отгоре. Виж примерната статия [„Как поддържам този блог"](posts/kak-podarzham-bloga.md) за жив пример.

### 🖼️ Да смениш снимките

В момента сайтът използва временни (placeholder) SVG снимки, ясно надписани с "Твоята снимка тук" и подобни. За да ги смениш с истински:

- **Аватар в началото на страницата** → замени `images/avatar-placeholder.svg`
- **Снимка в секция „За мен"** → замени `images/about-placeholder.svg`
- **Корица на статия** → качи нова снимка в `images` и посочи пътя ѝ в полето `cover` на статията

Най-лесно е да качиш снимката си със същото име като плейсхолдъра (през **Add file → Upload files** в папка `images`) — тогава не се налага да променяш нищо друго. Ако ползваш друго име/формат (`.jpg`, `.png`), само обнови съответния път в `index.html` (за аватара и снимката "За мен") или в `cover:` полето на статията.

### ✍️ Да редактираш текста "За мен"

Отвори `index.html`, намери секцията с `id="about"` и редактирай директно текста между параграфите `<p>...</p>`.

## Технически детайли (за по-любопитните)

- Чист HTML/CSS/JS, без build стъпка — хоства се директно през GitHub Pages.
- Статиите се зареждат в реално време през публичното GitHub REST API директно от браузъра на посетителя — затова качването на файл е достатъчно.
- За да не се ударя лимитът от 60 анонимни заявки/час на GitHub API, сайтът прави само 1 заявка за списъка с файлове (вместо по една на статия), а съдържанието на всяка статия се кешира по нейния git hash — веднъж свалена статия не се сваля пак, докато не я редактираш.
- Ако GitHub Pages не е "хванал" последната промяна веднага, изчакай 1-2 минути и презареди страницата (Ctrl/Cmd + Shift + R за твърдо презареждане).

Този сайт е нарочно направен да се поддържа лесно — без инсталиране на нищо, без код, само през браузъра в GitHub.

## Как да добавиш нова статия

1. Отвори папката `posts` в repository-то в GitHub.
2. Натисни **Add file → Create new file** (или качи готов `.md` файл).
3. Напиши кратко "frontmatter" най-отгоре, по този образец:

```
---
title: Заглавието на статията
date: 2026-10-01
excerpt: Едно-две изречения за листинга на статиите.
cover: images/post-cover-1.svg
---
```

4. Под frontmatter-а пишеш статията с обикновен Markdown — заглавия с `##`, **удебелен текст** с `**...**`, *курсив* с `*...*`, списъци с `-`, линкове с `[текст](адрес)`.
5. Commit-ваш промяната — статията се появява автоматично в блога, подредена по дата (най-новите отгоре).

Не е нужно да пипаш `index.html`, `styles.css` или `script.js` изобщо.

## Как да смениш снимките

В момента сайтът използва временни (placeholder) снимки, маркирани ясно с надпис. За да ги смениш:

- качи новия файл в папката `images` с **същото име** като плейсхолдъра (например замени `avatar-placeholder.svg` с твоя `avatar-placeholder.jpg` и обнови пътя в `index.html`), или
- качи снимката с ново име и обнови съответния път в `index.html` / в `cover` полето на дадена статия.

## Технически детайли

Сайтът е чист HTML/CSS/JS без build стъпка, хостван директно през GitHub Pages. Статиите се зареждат в реално време през публичното GitHub API направо от браузъра на посетителя — затова качването на файл в `posts/` е достатъчно, без да пипаш код.
